# Ситуационный центр: мониторинг и инциденты (Кейс №4)

Диспетчерская служба птицеводческого предприятия для контроля микроклимата на 5 участках и управления жизненным циклом инцидентов.

---

## 📋 Описание проекта

Система обеспечивает автоматическую обработку телеметрии с датчиков (температура, влажность, вентиляция), выявление отклонений от технологических норм, дедупликацию событий, эскалацию сбоев (включая потерю связи STALE), контроль прав доступа (RBAC) и ведение аудита действий.

### Основные возможности
- **Движок правил A-1...A-5:** расчёт критичности (NORMAL, WARNING, CRITICAL, STALE), дедупликация повторов в окне 5 минут, автоматическое создание инцидентов при повторных авариях.
- **Жизненный цикл инцидентов:** валидация переходов (`NEW` → `ASSIGNED` → `IN_PROGRESS` → `CLOSED`) и блокировка некорректных операций.
- **Интерактивный CLI-интерфейс:** цветная визуализация реестра оповещений и сводных метрик с помощью библиотеки `rich`.
- **Встроенный модуль самодиагностики:** автоматический прогон 5 тестовых сценариев регламента (`T4-1`...`T4-5`).
